## 🛠 Tech Stack

**Web:** Next.js 16, React 19, Tailwind CSS 4  
**Desktop:** Electron 33 + electron-updater (wraps Next.js standalone, auto-update via GitHub Releases)  
**Shared:** TypeScript monorepo with `@portfolio/shared` package

---

## ✨ Highlights

- **Web + Desktop** from one codebase
- **Auto-update** — desktop app checks for updates on launch (electron-updater)
- **Offline-first contact form** — messages queue locally, auto-send on reconnect (desktop)
- **Live project data** — desktop fetches from `/api/projects` in real time
- **Dark/light mode** everywhere, CV page with print support
- **Hardened API** — rate limiting, honeypot, input validation, sanitized errors
