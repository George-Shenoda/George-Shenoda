## 🛠 Tech Stack

**Web:** Next.js 16, React 19, Tailwind CSS 4  
**Shared:** TypeScript monorepo with `@portfolio/shared` package

## ✨ Highlights

- **Offline-first contact form** — messages queue locally, auto-send on reconnect
- **Live project data** — fetches from `/api/projects` in real time
- **Dark/light mode** everywhere, CV page with print support
- **Hardened API** — rate limiting, honeypot, input validation, sanitized errors
